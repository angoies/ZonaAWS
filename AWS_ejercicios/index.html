    AWS Ejercicios¶

    Iniciación¶

    1. Crear una EC2 con una imagen diferente, por ejemplo Ubuntu o AWS Linux. Comprobar username.
    2. Instalar un servidor web en EC2, por ejemplo apache o nginx. Probar acceso exterior usando IP o nombre DNS.
    3. Desplegar sitio web sobre servidor del apartado anterior.
    4. Crear una plantilla para creación de EC2 que incluya script de instalación de docker.
    5. Desplegar servidor web nginx o apache sobre EC2 usando contenedores.
    6. Desplegar servidor web nginx o apache sobre EC2 usando contenedores exponiendo la aplicación en puerto diferente (por ejemplo 3000 o 5000). Modificar grupo seguridad
    7. Desplegar imagen docker propia en EC2.

    Profundización¶

    1. Realizar ejercicio completo propuesto en plataforma.
    2. Asociar IP elástica a EC2. Asociar IP a nombre dominio propio DNS, etc. Desplegar usando traefik.
    3. Desplegar traefik usando certificados.
